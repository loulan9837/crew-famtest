# 项目记忆历史选择下拉 · 开发实施文档

> **依赖**：`docs/项目记忆历史选择-PRD.md`、`memory_store.py`、`app_ui.py`
>
> **目标**：在不改变 `memory_store` 存储结构的前提下，为项目记忆及相关模块增加“最近项目记忆下拉选择”的能力，并在会话级别保留最近一次选择。

---

## 一、涉及模块与接口

| 模块 | 文件 | 说明 |
|------|------|------|
| 项目记忆 Tab | `app_ui.py::_render_module_memory` | 展示项目记忆、导入历史、知识库等 |
| 需求风险分析 | `app_ui.py::_render_module_risk_report` | 选择文档来源进行风险分析 |
| 文档问答（可选） | `app_ui.py::_render_module_chat` 或等价函数 | 基于项目记忆/粘贴内容做问答 |
| 存储 | `memory_store.py` | 提供 `list_recent(limit, project_id)` 接口 |

`memory_store.list_recent(limit, project_id)` 已经按时间倒序返回当前项目的历史记录，字段包含 `id / created_at / source_type / source_id / title / content / summary / project_id` 等。

---

## 二、统一的历史下拉封装

为避免在多个模块重复实现，建议在 `app_ui.py` 中增加一个小工具函数：

```python
from typing import Optional, Tuple, List, Dict

def _render_memory_history_select(
    key_prefix: str,
    label: str,
    empty_hint: str,
    project_id: str,
    limit: int = 20,
) -> Tuple[Optional[dict], List[dict]]:
    \"\"\"渲染一个项目记忆历史下拉框。

    返回 (selected_entry, entries_list)：
    - selected_entry: 用户当前在下拉中选中的 dict（memory_entries 的一条），若无则为 None
    - entries_list: 本次查询到的 entries 列表（便于下游复用）
    \"\"\"
    entries: List[Dict] = list_recent(limit=limit, project_id=project_id)
    if not entries:
        st.selectbox(label, options=["__EMPTY__"], index=0, disabled=True, label_visibility=\"collapsed\")
        st.caption(empty_hint)
        return None, []

    # 构造展示文案
    options = []
    for e in entries:
        created = e.get(\"created_at\", \"\")
        title = (e.get(\"title\") or e.get(\"source_id\") or \"未命名\").strip()
        src_type = e.get(\"source_type\", \"\")
        options.append(f\"[{created}] {title}（{src_type}）\")

    state_key = f\"{key_prefix}_last_memory_id\"
    # 尝试恢复上次选择
    last_id = st.session_state.get(state_key)
    default_index = 0
    if last_id is not None:
        for idx, e in enumerate(entries):
            if e.get(\"id\") == last_id:
                default_index = idx
                break

    sel = st.selectbox(
        label,
        options=options,
        index=default_index,
        key=f\"{key_prefix}_memory_select\",
    )
    if sel and sel in options:
        idx = options.index(sel)
        selected = entries[idx]
        st.session_state[state_key] = selected.get(\"id\")
        return selected, entries
    return None, entries
```

> 说明：  
> - `key_prefix` 用于区分不同模块（如 `"memory_tab"`, `"risk_report"`, `"chat_tab"`）；  
> - `state_key` 用来在会话期内记录最近一次选择的条目 ID。

## 三、项目记忆 Tab 中的集成

在 `_render_module_memory` 的导入历史区域上方，插入调用：

```python
project_id = _get_current_project()

st.markdown(\"**最近项目记忆**\")
selected_entry, entries = _render_memory_history_select(
    key_prefix=\"memory_tab\",
    label=\"选择一条项目记忆记录\",
    empty_hint=_get_text(T, \"memory_tab.history_empty\") or \"当前项目暂无项目记忆记录，请先导入需求文档或全回归用例。\",
    project_id=project_id,
    limit=20,
)

if selected_entry:
    # 可选：在项目记忆 Tab 中提供一个简要预览
    st.caption(\"选中记录的摘要与内容预览：\")
    prev_title = (selected_entry.get(\"title\") or selected_entry.get(\"source_id\") or \"未命名\").strip()
    st.markdown(f\"**{prev_title}**  ({selected_entry.get('created_at', '')})\")
    summary = (selected_entry.get(\"agent_summary\") or selected_entry.get(\"summary\") or \"\").strip()
    if summary:
        st.caption(\"摘要：\")
        st.markdown(summary[:500] + (\"…\" if len(summary) > 500 else \"\"))
```

时间轴原有实现可以保持不变，仅作为更详细的展开视图。

## 四、需求风险分析模块中的应用

在 `_render_module_risk_report` 中，已有逻辑：

```python
    source_options = [\"paste\", \"memory\"] if MEMORY_AVAILABLE else [\"paste\"]
    doc_source = st.radio(...)
    ...
    elif doc_source == \"memory\":
        entries = list_recent(limit=20, project_id=_get_current_project())
        ...
```

可改为复用统一封装：

```python
elif doc_source == \"memory\":
    selected_entry, entries = _render_memory_history_select(
        key_prefix=\"risk_report\",
        label=_get_text(T, \"risk_report.doc_source_memory\") or \"选择近期文档\",
        empty_hint=_get_text(T, \"chat_tab.doc_source_empty\") or \"项目记忆暂无需求文档，请先在「项目记忆」页导入。\",
        project_id=_get_current_project(),
        limit=20,
    )
    if selected_entry:
        doc_context = (selected_entry.get(\"content\") or selected_entry.get(\"summary\") or \"\").strip()
```

这样：

- 历史选择列表与项目记忆 Tab 的数据源和排序完全一致；
- 最近一次选择在同一会话内能通过 `risk_report_last_memory_id` 记忆下来。

## 六、异常与降级处理

- 若 `MEMORY_AVAILABLE` 为 False：
  - 上游模块已通过 `source_options = [\"paste\"]` 限制为仅粘贴模式；
  - `_render_memory_history_select` 不会被调用，避免错误。
- 若 `list_recent` 返回空：
  - 下拉控件禁用并显示 `empty_hint` 文案；
  - 后续逻辑需检查 `selected_entry is None`，并给出提示。

## 七、测试要点

1. **刷新后历史仍可见**：
   - 导入若干项目记忆记录；
   - 刷新页面，确认：
     - 项目记忆 Tab 中“最近项目记忆”下拉仍能列出这些记录；
     - 选择某条记录后能看到预览。
2. **会话内选择保持**：
   - 在项目记忆 Tab 中选择某条记录；
   - 切换到其他模块，再切回项目记忆 Tab；
   - 确认下拉默认选中仍为刚才那条记录。
3. **风险分析模块复用**：
   - 在项目记忆中导入几条记录；
   - 在需求风险分析模块选择“项目记忆”来源；
   - 确认下拉中出现相同记录，选择后能正确注入文档内容。
4. **双项目隔离**：
   - 在 Fambase 项目下导入几条记录并选择其中一条；
   - 切换到 RM11，新建几条记录；
   - 确认两个项目下的历史下拉各自只展示本项目数据，且会话内选择互不干扰。
