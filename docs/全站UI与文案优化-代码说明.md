## 本轮范围（与「全站」标题的关系）

PRD 七章覆盖多模块；**标题「全站」指产品级方向一致，不等于单轮提交已把七章全部做完同等深度的界面改造**。本轮实现可分为三类，避免与「全站优化」字面冲突：

| 类别 | 模块 / 区域 | 本轮情况 |
|------|-------------|----------|
| **A. `app_ui.py` 结构或交互有改** | 侧栏顺序与云端记忆折叠、生成用例（配置行/加载/空态）、历史空态与删除文案、项目记忆**临时磁盘风险**折叠、**§7.5 导入结果摘要**（需求粘贴 + 全回归聚合路径）、文档问答（caption 与输入门禁）、设置（返回弱化、页首说明） | 见下文 §2.1–§2.7 |
| **B. 仅 `config/ui_texts.yaml` 等文案** | 需求评审、需求风险分析、用例对话等 | **未改**对应 `app_ui.py` 函数结构；仅部分 **section_desc / 导航相关** 等键与全站术语统一（见 §2.8） |
| **C. 本轮未动代码** | 编辑 Agent 页、需求评审 / 风险报告 / 用例对话的**页面布局与组件树** | 与改版前一致；若需对齐 PRD 七章余量，**后续迭代**再做 |

**关联文档**：`docs/全站UI视觉风格与换肤方案.md` 中的设计令牌收口、侧栏/主区统一容器语言等，**本轮未执行**——见 §2.9。

## 二、按 PRD 条目的落地对照

### 2.1 侧栏（PRD §7.1）

- **顺序**：项目切换 → 当前项目说明 → **工作台导航** → **高级** → 弱品牌单行 → **云端记忆（默认折叠）** → 版本沉底。
- **云端记忆**：由侧栏顶部改为 `st.expander(..., expanded=False)` 包裹；`_render_cloud_memory_sidebar` 在未配置/无记录时输出 `caption`，避免空白折叠区无反馈。
- **品牌**：原独立标题+长 slogan 块改为 `app.sidebar_tagline_short` 单行 `caption`。
- **版本**：仍为 `caption`，格式略收紧（去掉冒号、用 `·` 连接构建时间），降低视觉权重。

**逻辑**：云端回填仍写入 `_cloud_memory_apply_payload` 并跳转「生成用例」，与改版前一致。

---

### 2.2 生成用例（PRD §7.2、§2.4）

- **配置状态**：主区仍以 **`st.caption`** 单行展示 Token/Key 是否已配置（语义上接近 PRD §4 蓝图中的「轻量状态」，**未**单独抽取 `MainHeader` 组件或独立「状态条」容器——见 §2.10）。
- **模型配置**：`expander` 标签取自 `run_tab.model_expander_label`；**未配置 Key 时自动展开**逻辑仍为 `expanded=not bool(defaults.get("gemini_key"))`，未改校验与调用顺序。
- **加载**：删除执行过程中的 **`st.progress` 假阶段**，仅保留 **`st.spinner`**，文案统一为 `run_tab.run_spinner`，符合「无阶段信息则单次加载」的边界。
- **无结果空态**：粘贴/上传尚无运行结果时，用 `_render_empty_state_card`（`card-style`）替代长句 `st.info`，文案键为 `empty_result_paste_*` / `empty_result_upload_*`。

**逻辑**：`run_upload_to_cases` 调用参数、成功/失败分支、历史写入、Excel 生成与改版前一致。

---

### 2.3 历史记录（PRD §7.3）

- 无记录时：使用空态卡片（`history_empty_title` + `history_empty_body`，并兼容回退到 `history_empty_state` 语义）。
- 删除确认：文案缩短为 `delete_confirm_msg`（后果与 Excel 关系仍明确）；**交互仍为二次确认**，未弱化 A 类风险。

---

### 2.4 项目记忆 · 临时磁盘风险（PRD §7.5 子集）

- 长警告：**默认仅一行** `memory_tab.ephemeral_storage_summary`（`caption`）。
- 全文：放入 **`expander`（`ephemeral_storage_detail_expander`）** 内，仍为 `st.warning`，不削弱风险可读性，仅减少首屏「警告墙」。

**逻辑**：未改 `_deploy_workspace_likely_ephemeral()` 判定与后续导入/同步代码路径。

---

### 2.5 PRD §7.5「导入结果多状态合并为一条摘要」

- **已实现（展示层）**：
  - **粘贴导入需求**（`mem_import_demand`）：本地成功句与云端同步结果合并为 **一条** `st.success` 或（含云端失败时）**一条** `st.warning`；文案键含 `memory_tab.import_demand_done`、`cloud_memory_sync_partial`。**不改变** `add_entry_with_dedup` / `sync_text_demand_to_cloud` 调用次数与返回值语义。
  - **全回归用例导入**（`_handle_full_regression_import`）：云端备份异常、知识库自动更新失败、语义索引提示等，收拢进 **同一次** `st.warning` 或 `st.success` 的正文（多行 `\n\n`），避免连续多条横幅。
- **仍为多段反馈、可后续再收拢的**：例如 **设计图批量导入**循环内对 `cloud_sync_notes` 的逐条 `st.caption`、以及 **手动拉取/推送云端**等独立操作区——未强行合并，以免误伤可读性。
- **未使用**仅展示用 `session_state` 缓冲键；聚合 **只影响当次渲染条数**。

---

### 2.6 文档问答（PRD §7.6）

- **文档不可用时**：原多处 `st.info` 改为 **`st.caption`**（`doc_source_unavailable` / `doc_source_empty`），避免与主任务区横幅抢焦点。
- **无正文门禁**：`doc_context` 仍来自既有逻辑（记忆拉取或粘贴）；无正文时通过 `_st_chat_input_kwargs(disabled=True)` 在支持 `disabled` 的 Streamlit 版本上禁用 `st.chat_input`；旧版本忽略该参数，行为与此前一致。
- **补充说明**：无正文且非「记忆源已说明原因」时，展示 `chat_tab.no_context_hint`；误发时的 `st.warning` 改为与 `no_context_hint` 对齐的短句。

### 2.7 设置（PRD §7.7）

- 「返回」：`type="secondary"`，并增加 `help`（`settings_tab.back_secondary_help`）。
- 页首说明：使用 `settings_tab.page_intro`，与表单聚合呈现一致。

### 2.8 其它文案（PRD §7.4、术语；YAML 为主）

- **`risk_report.section_desc`、`case_chat_tab.section_desc`** 等微调，强调与四 Agent 主流程关系；**对应页面布局与交互未在本轮改 `app_ui.py`**。
- **需求评审**：若仅有键位与全站一致，属 **B 类**（见文首表）。

### 2.9 `全站UI视觉风格与换肤方案.md`（本轮未触及）

- 设计 **:root 令牌**、侧栏/主区统一容器语言、换肤阶段等：**本轮未改** `app_ui.py` 内既有全局 `<style>` / `:root` 块（除历史已存在的样式外无新增换肤向修改）。
- 本轮交付为 **交互与文案层**；与换肤方案的 **A/B 阶段** 可分开排期。

## 四、自检清单（Pre-Commit）

- **需求对齐**：展示与文案与 PRD 一致；未新增/删减功能模块与数据接口。
- **布局**：未在全局散落破坏型 `st.write`；侧栏与主区结构为容器级调整。
- **逻辑剥离**：无将 API/Agent 调用移入 UI；无伪造流水线阶段。
- **§9.4 主路径可交互（与 PRD 表格对齐）**：
  - 改版后主路径上**按钮可点击、输入框可聚焦与输入、文件上传可选**；快速切换模块后仍可操作。
  - **全页目视检查**：无异常层遮挡控件（与换肤方案 §八、PRD §9.4「主路径可交互 / CSS 回归」一致）；**本轮未改自定义 `pointer-events` 或新增遮挡装饰层**。
- **回归**：本地 `pytest` 全量通过（见下）；建议再冒烟：生成用例（上传/粘贴）、项目记忆导入、文档问答、设置保存。

## 六、推送前建议你手动点的页面

1. 侧栏：工作台/高级切换；展开「云端记忆快捷」、点一条回填（若环境有 Neon）。
2. 生成用例：无 Key 时模型区自动展开；执行时仅见 spinner、无假进度条；**确认主按钮、上传、粘贴区均可操作**。
3. 历史：空列表卡片；删除二次确认文案。
4. 项目记忆：临时磁盘环境下风险摘要一行 + 展开详情；**导入区仍可上传/点按钮**（与 §9.4 一致）。
5. 文档问答：无文档时输入框禁用（Streamlit 新版本）或仅 caption（旧版）。
6. 设置：返回为次要按钮样式。
7. **§9.4 补充**：任意选 1～2 个未大改页面（如需求评审、风险报告、编辑 Agent）**快速点一遍**，确认无新增遮挡或无法点击。
