# 设计图导入（多选文件 + 多文件夹）· 开发实施文档

> **文档用途**：给研发与测试定义实现边界、接口约束和验收路径。  
> **对应 PRD**：`docs/设计图导入-PRD.md`。  
> **注意**：本文档描述实现方案，不包含代码提交。

---

## 一、实现目标（和 PRD 对齐）

本次实现必须满足：

- 支持 Finder 导入多文件；
- 支持 Finder 导入多文件夹并递归；
- 支持文件与文件夹混合；
- 支持格式：`png/jpg/jpeg/webp/pdf/fig/sketch`；
- 按文件内容 hash 去重；
- 单次总大小上限 `1GB`；
- 导入记录按 `current_project` 隔离；
- 允许部分成功并输出失败清单（文件名 + 原因）。

---

## 二、建议架构拆分

建议按三层拆分，避免 UI 与逻辑耦合：

1. **UI 层**（`app_ui.py`）  
   - 收集文件/目录选择结果；  
   - 展示进度、结果汇总、失败列表；  
   - 不做重逻辑。

2. **导入编排层**（新 service，建议如 `design_import_service.py`）  
   - 统一处理「文件 + 文件夹」输入；  
   - 递归扫描、格式过滤、总量校验、去重判定、批处理执行；  
   - 返回结构化结果给 UI。

3. **能力层**（已有能力复用）  
   - 解析（Vision / 文件读取）；  
   - memory_store 入库；  
   - Agent 摘要生成。

## 三、关键规则落地

### 3.1 文件夹多选与递归

- 目标：支持一次选择多个文件夹。  
- 兼容：浏览器不支持一次多目录时，允许多次追加目录后统一提交。
- 递归：扫描所有子目录，得到候选文件集合。

### 3.2 格式白名单

- 扫描阶段即做后缀过滤：  
  `png/jpg/jpeg/webp/pdf/fig/sketch`（大小写不敏感）。
- 不在白名单的文件记入失败清单，原因为「格式不支持」。

### 3.3 总大小上限 1GB

- 在导入前先计算本批次总大小；
- 超过 `1GB` 直接中断本批次，返回统一错误，不进入解析。

### 3.4 去重（hash）

- 使用文件内容 `SHA-256`；
- 去重作用域：`project_id + file_hash`；
- 命中去重时记入 `skipped`，不算失败。

### 3.5 按项目隔离

- 读取 `current_project` 作为导入上下文；
- 入库与查询均带 `project_id`；
- 禁止跨项目复用导入记录或去重缓存。

### 3.6 部分成功

- 单文件失败不影响整批继续；
- 最终输出：
  - `success_count`
  - `skipped_count`
  - `failed_count`
  - `failed_items: [{name, reason}]`

## 四、接口与数据结构建议

导入编排层建议返回统一结构：

```python
{
  "success_count": int,
  "skipped_count": int,
  "failed_count": int,
  "failed_items": [{"name": str, "reason": str}],
  "total_size_bytes": int,
  "project_id": str
}
```

单个文件内部处理建议结构：

```python
{
  "name": str,
  "path_or_virtual_id": str,
  "size": int,
  "ext": str,
  "hash": str,
  "status": "success" | "skipped" | "failed",
  "reason": str
}
```

## 六、测试计划（与 PRD AC 对齐）

### P0 必测

1. 多文件上传（同批）成功。
2. 多文件夹上传，能递归到子目录文件。
3. 文件+文件夹混合批次可执行。
4. 总大小 > 1GB 时整体拦截。
5. 重复文件在同一项目下被 hash 去重。
6. `FAMBASE -> RM11 -> FAMBASE` 项目切换后，记录按项目隔离且可恢复原项目上下文。
7. 批量中 1 个失败 + N 个成功时，显示部分成功与失败清单。

### 建议补测

- 同名不同内容文件；
- 不同目录同内容文件；
- 大批量文件下 UI 进度与响应不卡死。

## 七、风险与注意事项

- **浏览器目录选择能力差异**：需有多次追加目录的兼容流程。
- **`fig/sketch` 可解析性**：本期先作为可导入文件类型；若解析链路不支持，按失败项输出明确原因，不得导致整批失败。
- **性能风险**：递归扫描与 hash 计算建议流式处理，避免一次性占用过多内存。
- **安全风险**：目录读取必须限制在用户显式选择范围；禁止任意路径遍历。
